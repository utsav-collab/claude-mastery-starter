## The Problem: AI-Generated Design

AI-generated designs are easy to spot:

```
┌─────────────────────────────────────────────────┐
│  THE "AI AESTHETIC" (What to AVOID)             │
│                                                 │
│  ❌ Safe, boring colors                         │
│  ❌ Tight spacing (everything cramped)          │
│  ❌ Everything centered                         │
│  ❌ Too many elements                           │
│  ❌ Generic gradients                           │
│  ❌ Default fonts (Poppins, Roboto, etc.)       │
│                                                 │
└─────────────────────────────────────────────────┘
```

**If it looks like AI made it, it's not done.**

## The Design Philosophy

We do the OPPOSITE of AI defaults:

| AI Default | Premium Design |
|------------|----------------|
| Tight spacing | Generous whitespace |
| Everything centered | Intentional asymmetry |
| Safe colors | Purposeful, meaningful color |
| Many elements | Fewer elements, more impact |
| Generic fonts | Researched typography |
| Decorative gradients | Functional design |

STOP: This is the mindset shift. Quality over quantity.

## The Magazine Test

Ask yourself:

> "Would this appear in a design magazine... or a Canva template?"

| Canva Template | Design Magazine |
|----------------|-----------------|
| Everything centered | Intentional asymmetry |
| Decorative gradients | Purposeful color |
| Stock photos | Custom illustration |
| Tight spacing | Generous whitespace |
| Safe choices | Bold decisions |

If it looks like a template → **iterate**.
If it looks like a magazine spread → **celebrate**.

STOP: This is your quality bar. Magazine, not template.

## The Design Framework

We'll use three principles:

### 1. The 60-30-10 Rule
- 60% — Dominant (background)
- 30% — Secondary (cards, sections)
- 10% — Accent (CTAs only)

### 2. Generous Whitespace
- When in doubt, add more space
- 60% empty space minimum
- Let elements BREATHE

### 3. Typography Hierarchy
- ONE font family (maybe two)
- THREE hierarchy levels only
- Proper line height and letter spacing
