## How to Use Inspiration

### 1. Screenshot & Analyze
Don't just look — deconstruct:
- What makes it feel premium?
- How is whitespace used?
- What's the color ratio?
- How do animations feel?

### 2. Extract Patterns, Not Pixels
```
DON'T: Copy the exact layout
DO: Extract the principles
```

Example from Linear:
- Dense information, still readable
- Subtle hover states
- Monochrome with ONE accent
- Keyboard-first interactions

### 3. The "Why" Behind Great Design

| Site | What They Do | Why It Works |
|------|--------------|--------------|
| Linear | Monochrome + purple accent | Focus on content, accent draws action |
| Vercel | Black bg, white text, gradients | Bold, confident, technical |
| Stripe | Lots of whitespace, subtle animations | Premium, trustworthy, approachable |
| Raycast | Dense but organized | Power users want density with clarity |

## Design Patterns to Study

### Hero Sections
```
Type 1: Statement + CTA (Vercel style)
Type 2: Split with product screenshot (Linear)
Type 3: Interactive demo (Stripe)
Type 4: Video/animation background (Award sites)
```

### Feature Sections
```
Type 1: Bento grid (Apple style)
Type 2: Alternating left-right (Notion)
Type 3: Tab-based reveals (Linear)
Type 4: Scroll-driven animations (Codrops)
```

### Pricing Pages
```
Study: Vercel, Linear, Stripe
Patterns: Comparison tables, feature toggles, annual discount badges
```

## Red Flags — You're Not Ready to Ship

- [ ] Looks like a Bootstrap template
- [ ] Could be any company's website
- [ ] No personality or brand voice
- [ ] Default shadows and rounded corners
- [ ] Stock photos
- [ ] Generic gradient backgrounds
- [ ] Too many fonts
- [ ] No hover states

## Green Flags — Ship It!

- [x] Someone would screenshot this
- [x] Clear visual hierarchy
- [x] Intentional color choices
- [x] Animations feel custom
- [x] Typography has character
- [x] Whitespace creates breathing room
- [x] Interactions feel delightful

## The Masterclass Standard

> "If it doesn't look like it could win an Awwward, iterate."

Your app should make people ask: "Who designed this?"
Not: "Did AI make this?"
