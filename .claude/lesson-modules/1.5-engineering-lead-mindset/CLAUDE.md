## What You Actually Do

As Engineering Lead, your job is:

### 1. 📋 Define the Vision
"What are we building and why?"

- Write the Epic (big picture)
- Break into Features (chunks)
- Create Tickets (specific tasks)

### 2. 👥 Assign the Team
"Who handles what?"

- Product Owner Agent → defines requirements
- Backend Agent → handles data and APIs
- Frontend Agent → creates the UI
- Creative Agent → makes it special

### 3. 🎯 Review the Work
"Is this what we wanted?"

- Check agent output
- Request changes
- Approve and merge

### 4. 📚 Maintain Context
"What does everyone need to know?"

- Keep CLAUDE.md updated
- Document decisions
- Track what's done

STOP: You don't code. You lead. Big difference in results!

## The PRD: Your Master Document 📋

Professional teams use a **PRD** — Product Requirements Document.

This lives in **Notion** (or similar) and contains:

| Section | What It Includes |
|---------|------------------|
| **Vision** | What we're building and why |
| **Epics** | The major chunks of work |
| **Features** | Specific functionality |
| **Tickets** | Individual tasks for agents |
| **Design** | DLS, inspiration, guidelines |
| **Technical** | Stack, architecture, APIs |

> Your Notion PRD is the source of truth. Claude reads it, agents reference it.

STOP: The PRD is your master plan. Everything flows from it.
