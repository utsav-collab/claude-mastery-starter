# Agency-Worthy Design System

How to make your app look like it was designed by a premium agency, not generated by AI.

---

## The AI Aesthetic Problem

AI-generated UIs have tells:
- ❌ Too many gradients
- ❌ Purple/blue/teal overload
- ❌ Everything animated
- ❌ Generic stock imagery
- ❌ "Hero with floating elements" cliché
- ❌ Excessive glassmorphism
- ❌ Rainbow shadows everywhere

**The solution:** Restraint, intention, and authentic design thinking.

---

## Core Principles

### 1. One Accent Color

**Bad:** 5 colors fighting for attention
**Good:** Black/white + ONE accent

```css
/* Agency approach */
--background: #000000;
--foreground: #ffffff;
--muted: #71717a;
--accent: #84cc16;  /* ONE color that means something */
```

**Rule:** If you can't justify why a color exists, remove it.

---

### 2. Intentional White Space

**AI tendency:** Fill every pixel
**Agency approach:** Let content breathe

```css
/* Generous spacing */
.section {
  padding: clamp(4rem, 10vw, 8rem) 0;
}

.card {
  padding: 2rem;
  /* Not 1rem - that's cramped */
}

/* Space between elements */
.content > * + * {
  margin-top: 1.5rem;
}
```

---

### 3. Typography Hierarchy

**AI tendency:** Same-ish sizes, everything "important"
**Agency approach:** Clear visual hierarchy

```css
/* Size scale with purpose */
.headline { font-size: clamp(3rem, 8vw, 6rem); font-weight: 600; }
.subheadline { font-size: clamp(1.25rem, 3vw, 1.5rem); font-weight: 400; color: var(--muted); }
.body { font-size: 1rem; line-height: 1.7; }
.caption { font-size: 0.875rem; color: var(--muted); }

/* The gap matters */
.headline + .subheadline {
  margin-top: 1rem;
}
```

---

### 4. Restrained Animation

**AI tendency:** Everything bounces, floats, and pulses
**Agency approach:** Animation with purpose

```typescript
// GOOD: Subtle, purposeful
const fadeIn = {
  initial: { opacity: 0, y: 20 },
  animate: { opacity: 1, y: 0 },
  transition: { duration: 0.5, ease: [0.25, 0.46, 0.45, 0.94] }
};

// BAD: Circus mode
const badAnimation = {
  animate: {
    scale: [1, 1.1, 1],
    rotate: [0, 5, -5, 0],
    backgroundColor: ['#ff0000', '#00ff00', '#0000ff'],
  }
};
```

**Rule:** If you can remove an animation and nothing is lost, remove it.

---

### 5. Authentic Imagery

**AI tendency:** Generic stock photos, Unsplash random
**Agency approach:** Curated, consistent imagery

| Instead of... | Use... |
|---------------|--------|
| Random Unsplash | Curated collection from one photographer |
| Generic "people working" | Real team photos or illustrated brand assets |
| AI-generated art | Commissioned illustrations or photography |
| Stock icons | Custom icon set (one style throughout) |

## Layout Patterns That Work

### The Bento Grid (When Done Right)

```tsx
// GOOD: Intentional asymmetry
<div className="grid grid-cols-4 gap-4">
  <div className="col-span-2 row-span-2">Hero card</div>
  <div>Small 1</div>
  <div>Small 2</div>
  <div className="col-span-2">Wide card</div>
</div>

// BAD: Random sizes
<div className="grid">
  <div className="col-span-3">???</div>
  <div className="col-span-1 row-span-3">???</div>
  {/* No logic to the layout */}
</div>
```

### The Split Screen

```tsx
<div className="grid md:grid-cols-2 min-h-screen">
  <div className="flex items-center p-12">
    {/* Content - always aligned, never floating */}
    <div className="max-w-md">
      <h1>Headline</h1>
      <p>Subtext</p>
      <Button>CTA</Button>
    </div>
  </div>
  <div className="bg-accent">
    {/* Visual - full bleed, no random floating elements */}
  </div>
</div>
```

### The Editorial Stack

```tsx
<article className="max-w-2xl mx-auto">
  <header className="mb-16">
    <span className="text-sm text-muted uppercase tracking-wider">Category</span>
    <h1 className="text-5xl font-bold mt-4">Headline That Breathes</h1>
    <p className="text-xl text-muted mt-6">Subtitle with enough space</p>
  </header>

  <div className="prose">
    {/* Content with generous line-height */}
  </div>
</article>
```

## Component Styling Rules

### Buttons

```tsx
// Agency button: Simple, confident
<button className="
  px-6 py-3
  bg-accent text-black
  font-medium
  hover:bg-accent/90
  transition-colors
  /* No shadows, no borders, no gradients */
">
  Get Started
</button>

// Secondary: Ghost style
<button className="
  px-6 py-3
  border border-zinc-800
  text-white
  hover:bg-zinc-900
  transition-colors
">
  Learn More
</button>
```

### Cards

```tsx
// Agency card: Clean edges, subtle depth
<div className="
  bg-zinc-900
  border border-zinc-800
  rounded-xl
  p-6
  /* No hover:scale, no shadows, no gradients */
">
  <h3 className="font-medium">Title</h3>
  <p className="text-muted mt-2">Description</p>
</div>
```

### Forms

```tsx
// Agency input: Invisible until focused
<input className="
  w-full
  bg-transparent
  border-b border-zinc-800
  py-3
  focus:border-accent
  focus:outline-none
  transition-colors
  placeholder:text-zinc-600
"/>
```

## Color Philosophy

### Monochrome First

Design in grayscale first. Add color only where it MEANS something.

```
Black (#000)     → Background
Zinc-900 (#18181b) → Elevated surfaces
Zinc-800 (#27272a) → Borders
Zinc-400 (#a1a1aa) → Secondary text
White (#fff)     → Primary text
Accent (#84cc16) → CTAs, highlights, emphasis
```

### The 60/30/10 Rule

- **60%** - Dominant (background, large surfaces)
- **30%** - Secondary (cards, sections)
- **10%** - Accent (CTAs, highlights)

## What Agencies Actually Do

1. **Start with content, not components**
   - Write the copy first
   - Design around the message
   - Don't pick a template and fill it

2. **Reference real sites, not Dribbble**
   - Stripe, Linear, Vercel, Raycast
   - Working products, not concept shots

3. **Test with real data**
   - Long names, missing images, edge cases
   - If it only looks good with perfect data, it's not good

4. **Kill your darlings**
   - That animation you love? Probably unnecessary
   - That gradient? Adds nothing
   - That third font? Confusion

## Quick Self-Check

Before shipping, ask:

- [ ] Can I remove this animation without losing meaning?
- [ ] Am I using more than one accent color?
- [ ] Is there enough white space to breathe?
- [ ] Would this look good with ugly placeholder text?
- [ ] Does every element have a PURPOSE?
- [ ] Would Stripe/Linear/Vercel do this?
