## Quick Assessment: Where Should I Start?

Answer these questions to find your path:

```
Q1: Have you used a terminal before?
    ├── NO  → Start at /start-0-2 (Terminal Basics)
    └── YES → Continue to Q2

Q2: Do you understand what Claude Code is?
    ├── NO  → Start at /start-0-1 (What is Claude Code?)
    └── YES → Continue to Q3

Q3: Have you used vibe coding tools (Lovable, Bolt, v0)?
    ├── NO  → Start at /start-1-1 (The Vibe Coding Problem)
    └── YES → Continue to Q4

Q4: Do you know how to use @ mentions, modes, and CLAUDE.md?
    ├── NO  → Start at /start-1-2 (The Claude Code Difference)
    └── YES → Continue to Q5

Q5: Do you understand agents, skills, and hooks?
    ├── NO  → Start at /start-1-6 (Agent Mental Model)
    └── YES → Skip to Module 2!
```

## The "I'm Lost" Recovery Path

If you're stuck at any point:

1. **App broken?** → `git checkout .` (reverts to last commit)
2. **Claude confused?** → `/clear` and start fresh
3. **Don't understand a concept?** → Go back one lesson
4. **Need help?** → Type `/workshop-help` for guidance

---

## Post-Workshop: Continue Learning

After the workshop, continue with:

1. **Build your own features** — Use the Epic → Feature → Ticket structure
2. **Create custom skills** — Save your workflows as `/my-skill` commands
3. **Set up hooks** — Automate quality checks
4. **Explore agents** — Build your own specialized agents
